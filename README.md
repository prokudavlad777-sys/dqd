# GunsPlugin (Paper 26.3)

Команда `/gun` дає револьвер або обріз і 64 патрони до нього.

## Як користуватись
- `/gun` — меню вибору зброї
- `/gun revolver` або `/gun shotgun` — отримати зброю одразу
- **ПКМ** — стріляти
- **F** (обмін предметів між руками) — перезарядити

## Зброя
| | Револьвер | Обріз |
|---|---|---|
| Шкода | 10 HP (пів шкали гравця) | 2 патрони × 270 впритул (540 — вбиває вардена) |
| Барабан | 6 | 2 (обидва стволи за один постріл) |
| Перезарядка | 2,5 с | 2 с |

Шкода обріза падає з відстанню (повна до 5 блоків, далі зменшується).
Усі числа змінюються у `plugins/GunsPlugin/config.yml`.

## Збірка на GitHub
1. Створи репозиторій і залий туди **весь вміст** цієї папки (разом з `.github`).
2. Відкрий вкладку **Actions** — збірка запуститься сама після push.
3. Коли збірка зелена, відкрий її й завантаж:
   - **GunsPlugin-jar** → `GunsPlugin-1.0.0.jar` кидаєш у `plugins/` на сервері;
   - **GunPack** → `GunPack.zip` (ресурс пак) і `GunPack.sha1`.

## Збірка на своєму ПК (Windows)
Встанови JDK 25 (https://adoptium.net) і запусти `build.bat`. Якщо Gradle не встановлено, скрипт сам його завантажить. Готові файли з'являться в папці `dist`.

## Ресурс пак
Текстури лежать у `resourcepack/`. Щоб гравці бачили їх автоматично:
1. Створи тег, наприклад `v1.0.0` (`git tag v1.0.0 && git push --tags`) — GitHub Actions
   прикріпить `GunPack.zip` до Release.
2. Скопіюй пряме посилання на `GunPack.zip` з Release.
3. У `server.properties`:
   ```
   resource-pack=<посилання на GunPack.zip>
   resource-pack-sha1=<вміст GunPack.sha1, тільки хеш>
   ```
4. Перезапусти сервер.

Ресурс пак без моделей: він просто підміняє текстури чотирьох ваніль­них предметів
(осколок диска 5 = револьвер, відлунний осколок = обріз,
призмариновий осколок = патрони револьвера, призмариновий кристал = патрони обріза).
Предмети плоскі, 1 піксель товщини (звичайна ваніль­на модель generated).
Без ресурс паку зброя теж працює, але виглядає як ці ваніль­ні предмети.
